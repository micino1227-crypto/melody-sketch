# メロディ・スケッチ

Sunoなどで作曲するときの「もとになるメロディ」を、ブラウザだけで作れるアプリです。

- 楽器ごとのトラック（メロディ・コード・ベース・ドラムなど）を並べて、音のブロックを指で置く・ずらす・のばす
- 鍵盤やドラムパッドで弾いて録音
- 7ジャンル・37種・11,100曲のサンプル曲
- 音声ファイル（MP3・ボイスメモなど）の読み込み、メロディの読み取り
- MP3／WAVで書き出し

`index.html` をブラウザで開くだけで動きます（インストール不要）。作った曲はお使いのブラウザの中に保存されます。

## 使用ライブラリ

- [lamejs](https://github.com/zhuker/lamejs) 1.2.1 — LAME MP3エンコーダのJavaScript版（[LAME](https://lame.sourceforge.io/)、LGPL-3.0）。改変せずに `lame.min.js` として同梱しています。ライセンスは `LICENSE-lamejs.txt` を参照してください。
